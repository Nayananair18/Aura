# 🧪 Layer 3: Error Level Analysis (ELA)

## 🔬 Overview & Compression Dynamics

Error Level Analysis (ELA) evaluates JPEG compression degradation across an image to detect digital manipulation, localized Photoshop editing, AI infilling, or spliced compositing.

When a photo is taken by a camera, the entire image is saved at a single, uniform JPEG compression level. If a portion of the image is later edited, modified, or generated by an AI model and pasted into the photo, that modified region will have a **different compression error level** compared to the rest of the image.

---

## ⚙️ Algorithmic Process

```
[ Uploaded Image Buffer ]
         │
         ├───► 1. Save Image at Fixed 90% JPEG Quality Threshold
         │
         ├───► 2. Compute Absolute Pixel Delta Map: |Pixel_Original - Pixel_Recompressed|
         │
         ├───► 3. Scale Pixel Delta Values (Amplification Factor = 10x)
         │
         └───► 4. Calculate Global & Sub-Block ELA Variance (0.0 - 100.0)
```

1. **Re-compression**: The original image buffer is re-encoded into JPEG format at a standardized $90\%$ quality setting.
2. **Absolute Difference Calculation**: For every RGB pixel $(r, g, b)$, compute the absolute difference:
   $$\Delta_{RGB} = |R_{\text{orig}} - R_{\text{recomp}}| + |G_{\text{orig}} - G_{\text{recomp}}| + |B_{\text{orig}} - B_{\text{recomp}}|$$
3. **Variance Analysis**:
   - **Uniform Low ELA Variance**: Indicates consistent single-pass compression across the entire frame (Authentic Photo).
   - **High Localized ELA Variance**: Indicates spliced elements, localized AI generative fill, or digital retouching.
